Technical Design Document

1. Project Name

Disaster Management System

2. Introduction

The Disaster Management System is a Python-based application that provides basic disaster information and safety instructions to help users prepare for emergencies.

3. System Architecture

The application consists of three main components:

1. User Interface: Displays the menu and accepts user choices.
2. Application Logic: Processes the selected disaster type.
3. Safety Information Module: Displays relevant safety instructions.

4. System Workflow

1. The user starts the application.
2. The system displays a menu of disaster types.
3. The user selects a disaster.
4. The application displays safety instructions.
5. The user can select another disaster or exit.

5. Technologies Used

- Programming Language: Python 3
- Interface: Command-line interface
- Data Storage: Python dictionary

6. Disaster Categories

- Earthquake
- Flood
- Cyclone
- Fire

7. Limitations

The current prototype does not provide live disaster alerts, GPS tracking, or emergency service integration.

8. Future Enhancements

- Real-time disaster alerts
- Location-based emergency information
- Emergency contact integration
- A web-based user interface
